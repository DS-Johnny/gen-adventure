INSTRUÇÕES PARA GERAÇÃO DE HISTÓRIA INTERATIVA EM CSV
======================================================

OBJETIVO
--------
Criar uma história interativa no formato CSV (UTF-8, separador vírgula) com exatamente 40 linhas (ou número especificado), onde cada linha representa uma "página" da história. O jogador avança fazendo escolhas que o levam de um ID a outro, até chegar a páginas sem options (finais).

ESTRUTURA DO CSV (3 COLUNAS OBRIGATÓRIAS)
-----------------------------------------
id,text,options

- id: Inteiro de 1 a N (sequencial, começando em 1)
- text: String com a narrativa da página. Pode conter diálogos, descrições, sensações. Deve terminar com uma situação que exija escolha.
- options: String representando uma lista de dicionários no formato JSON-like. Exemplo: "[{'text da escolha': id_destino}, {'Outra escolha': id_destino2}]"

REGRAS OBRIGATÓRIAS (VALIDAÇÃO E CONSISTÊNCIA)
-----------------------------------------------

1. IDs:
   - O arquivo deve ter exatamente N entradas, com ID de 1 até N.
   - Nenhuma escolha pode apontar para um ID fora do intervalo 1..N.
   - Nenhuma escolha pode apontar para o próprio ID (loops infinitos não intencionais são permitidos, mas com cautela).
   - Páginas finais devem ter options = "[]" (lista vazia).

2. Formato da coluna options:
   - Deve ser uma string que representa uma lista de dicionários.
   - Cada dicionário contém UMA chave (text da escolha) e UM valor inteiro (ID de destino).
   - Use aspas simples por consistência.
   - Exemplo válido: "[{'Ir para a floresta': 2}, {'Ficar na cabana': 3}]"
   - Exemplo inválido (não use): "[{'Ir': 2, 'Ficar': 3}]"

3. text:
   - Cada página deve conter context suficiente para o jogador entender a situação.
   - Use diálogos entre aspas para dar vida aos personagens.
   - Adicione sensações (visuais, sonoras, táteis) para imersão.
   - Páginas finais podem conter desfechos emocionantes, tristes, engraçados ou abertos.

4. Quantidade de options:
   - Recomendado: 2 a 3 options por página (exceto páginas finais).
   - Evite options únicas, a menos que seja uma transição narrativa intencional.
   - Páginas com 4 ou mais options são permitidas se bem escritas.

BOAS PRÁTICAS DE NARRATIVA INTERATIVA
--------------------------------------
- Causa e consequência: cada escolha deve levar a um resultado coerente.
- Rejogabilidade: inclua finais diferentes e caminhos ocultos.
- Personagens marcantes: use diálogos característicos.
- Ritmo: alterne entre ação, diálogo e introspecção.
- Surpresas: reviravoltas (ex: aliados que viram vilões, verdades ocultas).
- Evite vieses narrativos: nenhuma escolha deve ser claramente "certa" ou "errada" à primeira vista.

CHECKLIST DE VALIDAÇÃO (ANTES DE ENTREGAR)
------------------------------------------
[ ] O arquivo tem exatamente N linhas (N = número de IDs).
[ ] IDs são sequenciais de 1 a N.
[ ] Nenhuma opção aponta para ID > N ou < 1.
[ ] Nenhuma opção é '[]' (string vazia) com conteúdo textual — use "[]" apenas para finais.
[ ] As options usam aspas simples para as chaves e aspas duplas para o CSV como um todo.
[ ] Não há linhas em branco no meio do arquivo.
[ ] O text não contém vírgulas não escapadas (use aspas duplas ao redor do campo).
[ ] Todos os destinos existem e são alcançáveis a partir da página 1 (grafo conexo).

INSTRUÇÕES PARA O AGENTE DE IA
------------------------------
1. Receba do usuário o tema da história (ex: "Universo de Harry Potter", "Cyberpunk", "Velho Oeste", "Friends", "Jujutsu Kaisen").
2. Estruture a história com 40 entradas, IDs de 1 a 40.
3. Cada escolha deve apontar para um ID entre 1 e 40.
4. Utilize diálogos, descrições e reviravoltas típicas do tema escolhido.
5. Finalize com páginas sem options (options = "[]").
6. Garanta que o grafo de decisões seja conexo a partir do ID 1.

8. Entregue o arquivo para download ou exiba o conteúdo formatado.

COMPATIBILIDADE COM CSV / PANDAS (OBRIGATÓRIO)
----------------------------------------------

IMPORTANTE:
O arquivo será lido automaticamente por pandas.read_csv().

Para evitar ParserError, siga obrigatoriamente todas estas regras:

1. Cada linha deve conter EXATAMENTE 3 colunas:
   id,text,options

2. O separador entre colunas é SEMPRE vírgula:
   ,

3. O campo text deve SEMPRE estar entre aspas duplas:
   "text"

4. O campo options deve SEMPRE estar entre aspas duplas:
   "[{'Escolha': 2}]"

5. Nunca use vírgula dentro do text narrativo.
   Em vez de vírgula use:
   - ponto final .
   - ponto e vírgula ;
   - travessão —
   - reticências ...

6. Nunca use vírgula dentro do text das escolhas.

ERRADO:
'Ir até a porta, rapidamente'

CERTO:
'Ir até a porta rapidamente'

7. Aspas dentro da narrativa devem ser escapadas com dupla aspas:

Exemplo:
"Ela respondeu ""não"" e saiu"

8. Não gerar markdown.

9. Não usar ```csv

10. Retornar SOMENTE conteúdo CSV puro.

11. A primeira linha deve ser exatamente:

id,text,options

12. Todas as demais linhas devem manter exatamente o mesmo padrão estrutural.

13. Antes de finalizar valide internamente:
   - número de colunas = 3
   - separador = vírgula
   - text sem vírgulas internas
   - escolhas sem vírgulas internas
   - CSV compatível com pandas.read_csv()
